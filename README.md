# SiteBiologia
Site de Biologia para o projeto da biomaquete sobre o sistema endócrino

# Ideia inicial do site:
    Site com objetivo de complementar a apresentação da Biomaquete sobre o sistema endócrino
    O site teria 2 opções iniciais:
        - Sistema endócrino (PNG 2D)+ explicações sobre os órgãos que compõem o sistema.
        - Minigame interativo para entender melhor sobre o tema (ideia subjetiva).
    O site será disponibilizado a partir de um QRCode
    Linguagens usadas: React + TailWind CSS (inicialmente)
    Usarei hierarquia e código do Backend usados na biblioteca/site Next.js
